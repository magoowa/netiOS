# Technologie i licencje netiOS 0.4.19

Składniki aplikacji, środowiska i narzędzia opisuje [README](../README.md#technologie-zewnętrzne-i-licencje). Pełne teksty licencji zasobów są w [app/assets/licenses](../app/assets/licenses); licencja Shaka Player jest dołączana z jego pakietu do app/vendor/SHAKA-LICENSE w IPK.

## Zależności npm

Wykaz generuje polecenie `npm run licenses` z package-lock.json. Obejmuje 232 unikalnych par nazwa–wersja wymaganych zależności bez wpisów extraneous, także pakiety opcjonalne i pośrednie. Do IPK z npm trafia skompilowany Shaka Player z licencją; pozostałe pakiety służą narzędziom.

Różne wersje tego samego pakietu odpowiadają wymaganiom różnych bibliotek nadrzędnych. Nie wolno scalać niezgodnych głównych wersji samym wymuszeniem numeru. npm 12.2.1 pomija shrinkwrap dostawcy CLI i obsługuje poprawki bezpieczeństwa zapisane w overrides projektu.

Licencje pochodzą z metadanych lockfile. Brakujące wpisy ar-async, buildcheck, cpu-features i ssh2 zweryfikowano w ich plikach LICENSE (MIT). Pełne warunki i informacje autorów zachowują pierwszeństwo przed tą tabelą.
